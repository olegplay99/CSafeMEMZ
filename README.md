# CSafeMEMZ

**CSafeMEMZ** — безопасная визуальная имитация **MEMZ** для Windows, написанная на C.

Проект создаётся с нуля с целью максимально точно передать **узнаваемый стиль, атмосферу, последовательность событий и характерное поведение MEMZ**, но без выполнения реальных разрушительных действий.

---

# Цель проекта

Главная цель CSafeMEMZ — не просто сделать набор случайных эффектов.

Мы хотим создать программу, которая при запуске постепенно создаёт ощущение, что компьютер оказался под воздействием чего-то вроде MEMZ:

```text
Обычный Windows
      ↓
Первое предупреждение
      ↓
Первые странности
      ↓
Фейковые системные события
      ↓
Искажения экрана
      ↓
Всё больше хаоса
      ↓
Кульминация
      ↓
Финальная сцена
      ↓
Завершение программы
```

Каждое событие должно быть частью общей последовательности, а не просто случайным эффектом.

Поэтому при разработке проекта приоритет отдаётся **узнаваемости MEMZ**, а не количеству эффектов.

---

# Почему CSafeMEMZ

Оригинальный MEMZ известен тем, что постепенно превращает работу Windows в хаотичное шоу из различных визуальных и системных событий.

CSafeMEMZ использует эту идею исключительно как основу для **безопасной симуляции**.

Если оригинальная программа выполняла бы потенциально опасное действие, CSafeMEMZ должен вместо этого показать его визуальную имитацию.

Например:

```text
Реальное опасное действие
          ↓
     НЕ выполняется
          ↓
Визуальная имитация события
```

Таким образом, программа должна выглядеть убедительно, но не должна уничтожать данные или ломать систему.

---

# Безопасность

**Безопасность — обязательная часть проекта.**

CSafeMEMZ не является настоящим вредоносным ПО и не должен становиться им.

Программа не должна:

* удалять пользовательские файлы;
* шифровать файлы;
* форматировать диски;
* изменять MBR;
* изменять загрузчик Windows;
* повреждать файловую систему;
* устанавливать скрытый автозапуск;
* воровать данные;
* изменять системные настройки без явного разрешения;
* отключать защитные механизмы Windows;
* выполнять другие реальные destructive-действия.

Если для создания визуального эффекта требуется имитация подобного события, оно реализуется **только визуально**.

# Основная идея

CSafeMEMZ должен восприниматься как единая программа, а не как коллекция несвязанных демонстрационных эффектов.

Поэтому мы не стремимся сделать:

```text
эффект → эффект → эффект → случайная анимация → пончик → ДНК
```

Вместо этого нужна последовательность, в которой события постепенно становятся всё более странными.

Пример общей логики:

```text
INTRO
  ↓
EARLY EVENTS
  ↓
WINDOW CHAOS
  ↓
SCREEN DISTORTION
  ↓
MEMZ EVENTS
  ↓
HEAVY GLITCH
  ↓
FINAL CHAOS
  ↓
OUTRO
```

Конкретная последовательность будет формироваться во время разработки.

# `src/main.c`

Главная точка входа программы.

`main.c` не должен содержать реализацию всех эффектов.

Его задача — запустить основные компоненты программы в правильном порядке.

Упрощённо:

```text
main
 │
 ├── Intro
 │
 ├── Engine
 │      │

```

Чем меньше логики находится непосредственно в `main.c`, тем проще поддерживать проект.

# Последовательность событий

Порядок событий является одной из самых важных частей проекта.

Вместо полностью случайного выбора эффектов движок должен постепенно управлять уровнем хаоса.

Условно:

```text
LEVEL 0
Обычное состояние
        ↓
LEVEL 1
Небольшие странности
        ↓
LEVEL 2
Фейковые системные события
        ↓
LEVEL 3
Искажения Windows
        ↓
LEVEL 4
Сильный визуальный хаос
        ↓
LEVEL 5
Финальная последовательность
```

Это позволяет сделать программу более похожей на единое представление, а не на случайный генератор.
